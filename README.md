# git-practice

A small practice repository for learning the basic Git workflow
(`add`, `commit`, `push`).

## Files

| File | Description |
|------|-------------|
| `README.md` | Project overview |
| `.gitignore` | Files Git should ignore (Python template) |
| `LICENSE` | MIT License |
| `main.py` | Entry point of the sample program |
| `calculator.py` | Simple calculator functions |
| `requirements.txt` | Python dependencies (none required) |

## Usage

```bash
python3 main.py
```
